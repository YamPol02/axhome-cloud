# AX HOME Cloud brand assets

`icon.png` and `logo.png` show only the Hik-Connect app symbol, without its wordmark. They are transparent PNG crops of the official Hik-Connect logo from Hikvision Iberia; the colored rounded-square mark itself is unchanged. `@2x` files provide the same image at double resolution. Home Assistant 2026.3+ serves these custom integration assets from this folder.
